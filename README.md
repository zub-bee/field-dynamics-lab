## How to run the application

Before running the application for the first time, use `go mod tidy` to download the necessary dependencies.

```
$ go mod tidy
```

You will also need a working PostgreSQL installation and a valid DSN (data source name) for connecting to the database.

Please open the `cmd/api/main.go` file and edit it to include your DSN as the default value. The DSN must be in the format `user:pass@localhost:port/db` and **must not** be prefixed with `postgres://`.

```
cfg.db.dsn = env.GetString("DB_DSN", "YOUR DSN GOES HERE")
```

Then run the application:

```
$ go run ./cmd/api
```

This will start a server listening on `http://localhost:7117`. Try visiting the `http://localhost:7117/status` endpoint in your web browser!

Now that your application is up and running, check out the [Getting started](https://autostrada.dev/docs/api/getting-started) guide in the online documentation for next steps.
